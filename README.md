# VEKTOR Intelligence (VI)

## Vision
Direction for every mind.

## Core Idea
We don't just give answers.  
We show the geometry of what you currently believe vs expert truth — then give clear direction to close the gap.

## Key Features (Phase 1–2 focus)
- Real-time dual-graph visualization (WebGL2)
- Natural language + voice input → SKG generation
- Tiered feedback + misconception highlighting
- Adaptive "Today's Path" recommendations
- Teacher live heatmap & class tools
- Researcher cohort analysis & exports
- Admin DKG editor & platform oversight

## Tech Stack
- Frontend: Next.js 14/15, TypeScript, Tailwind, Zustand, raw WebGL2
- Backend: FastAPI, Python 3.11+, NetworkX, sentence-transformers
- AI: Gemini API (primary), Claude fallback, local ML
- Infra: Vercel (frontend), Railway/Render (backend), Supabase/Firebase

## Status
Early development – Phase 1 MVP in progress (Mathematics focus)
