# VEKTOR Intelligence (VI)

**Direction for every mind.**

VEKTOR Intelligence is a **production-grade STEM intelligence platform** that maps what a student currently believes, compares it to expert-validated domain knowledge, and provides a **visual, AI-driven direction** to close the gap.

Built by **Team SIG Reality Spectra** at **VIT Pune**, VI goes beyond traditional "correct answer" tools by **visualizing the "shape" of a student's misunderstanding**.

---

## 🧠 Core Concept: Dual-Graph Analysis

The platform's primary innovation is the **real-time comparison** of two distinct knowledge structures:

- **Student Knowledge Graph (SKG)**: A live map of a student's mental model, extracted from natural language queries using AI.
- **Domain Knowledge Graph (DKG)**: An expert-validated "source of truth" authored by human researchers to ensure absolute academic accuracy.

**The Gap**: VI identifies **missing nodes** (gaps) and **reversed edges** (misconceptions) to provide directional pedagogical feedback.

---

## 🎨 AI-Based Custom Rendering Engine

VEKTOR features a custom-built, high-performance rendering pipeline designed for **scientific precision** and **cinematic visual fidelity**.

### Demoscene-Level WebGL2 Architecture

- **Raw WebGL2 Implementation**: Bypasses heavy libraries like Three.js for raw WebGL2 and GLSL, allowing total control over GPU resources and bundle size.
- **Analytical SDF Shaders**: Uses pure fragment shader rendering with Signed Distance Functions (SDFs), eliminating complex geometry buffers.
- **GPU-Accelerated Physics**: All animation math (Keplerian orbits, wave interference, etc.) is offloaded to the GPU for consistent **60fps** performance.
- **High-Density Instancing**: Uses `ANGLE_instanced_arrays` to render thousands of interactive STEM symbols or particles in a single draw call.

### AI-Parametric Simulation Engine

- **Hybrid Generation**: AI-extracted parameter objects drive mathematically verified WebGL templates.
- **u_phase Morphing**: Real-time morphing between **"YOUR MODEL"** (student's belief) and **"EXPERT MODEL"** (scientific truth) using a unique `u_phase` uniform.
- **Context-Aware Visuals**: Every simulation is uniquely parameterized by the student's actual query, making the visual output a direct reflection of their specific misconception.

## 📊 Knowledge Tier System (T1–T4)

Every session classifies student understanding into one of four diagnostic tiers:

- **T1 (Aligned)**: Mental model fully matches the expert DKG.
- **T2 (Gap)**: Surface understanding present, but key connections are missing.
- **T3 (Misconception)**: Structural error in the mental model that blocks downstream learning.
- **T4 (Fragmented)**: Insufficient data to map a coherent model.

---

## ⚖️ Rules of the Platform

- **Human-Authored DKGs**: Domain Knowledge Graphs are written by subject experts — **never generated by AI**.
- **Socratic Tutoring**: The AI Tutor (Pro feature) is **strictly forbidden** from giving direct answers. It only asks guiding questions.
- **Performance First**: Device Pixel Ratio (DPR) capped at 1.5 to prevent VRAM pressure.
- **Design Precision**: Zero rounded corners on structural containers to emphasize technical accuracy.
